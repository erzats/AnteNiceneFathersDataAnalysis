# AnteNiceneFathersDataAnalysis

Analysis of Scripture citation patterns across the nine-volume *Ante-Nicene Fathers* ThML corpus. The pipeline extracts every tagged Bible reference, enriches it with metadata, and serves it through three interfaces: CSV/SQLite for researchers, an MCP server for AI-driven open-ended queries, and a Next.js web app for visual analysis.

## Architecture

```
texts/AnteNiceneVolume*.html   (source ThML, 46 MB)
        │
        ▼ python data_processer.py
anf_pipeline/                  (parsing, aggregation, export)
        │
        ├── outputs/           (CSV + SQLite — gitignored, generated)
        │     ├── references_structured.csv
        │     ├── book_counts_by_author.csv
        │     ├── book_counts_overall.csv
        │     ├── book_counts_volume_comparison.csv
        │     ├── parse_diagnostics.csv
        │     ├── analysis_report.md
        │     └── anf_references.sqlite
        │
        ├── web/src/data/      (JSON — committed, generated by pipeline)
        │     ├── summary.json
        │     ├── books.json
        │     ├── authors.json
        │     ├── psalms.json
        │     └── volume_comparison.json
        │
        └── mcp_server/        (MCP server — queries the SQLite DB)
```

## Quickstart

### Run the pipeline

```bash
python data_processer.py
```

Parses all 9 volumes and writes:
- `outputs/` — CSV files and SQLite DB
- `web/src/data/` — JSON files for the web frontend

### Ad hoc SQL

```bash
python data_processer.py --sql-query "SELECT book, COUNT(*) AS n FROM bible_references GROUP BY book ORDER BY n DESC LIMIT 10"
```

### Filtered query preview

```bash
python data_processer.py --query-author origen --query-book Ps --query-limit 20
```

## MCP Server

The MCP server exposes the SQLite DB to AI assistants for open-ended questions like:

- *"Which Psalm was most quoted in the 2nd century?"*
- *"Who cited deuterocanonical texts the most?"*
- *"Were any books never cited by any Church Father?"*

### Setup

```bash
pip install -r mcp_server/requirements.txt
```

### Run

```bash
ANF_DB_PATH=outputs/anf_references.sqlite python -m mcp_server.server
```

### Claude Desktop config

```json
{
  "mcpServers": {
    "anf-citations": {
      "command": "python",
      "args": ["-m", "mcp_server.server"],
      "env": {
        "ANF_DB_PATH": "/absolute/path/to/outputs/anf_references.sqlite"
      }
    }
  }
}
```

### Available tools

| Tool | Description |
|------|-------------|
| `search_citations` | Filter citations by book, author, testament, volume, confidence |
| `rank_books` | Top cited books, optionally by testament or author |
| `rank_authors` | Most prolific Church Fathers by citation count or book breadth |
| `rank_psalms` | Psalm chapter citation frequency |
| `get_author_coverage` | Books cited by each Father, incl. deuterocanonical |
| `find_unquoted_books` | Canonical books never cited (corpus-wide or per-author) |
| `citations_by_century` | Citation patterns grouped by century of each Father |
| `run_query` | Raw SQL SELECT against the `bible_references` table |

## Web Frontend

A Next.js app (deployed to Vercel) showing structured visual analysis.

### Setup

```bash
cd web
npm install
npm run dev
```

Build for Vercel:

```bash
npm run build   # produces web/out/ for static export
```

### Pages

| Page | Content |
|------|---------|
| `/` | Dashboard — totals, testament breakdown, top books/authors |
| `/books` | All cited books ranked by frequency, grouped by testament |
| `/authors` | All Church Fathers with citations, era, and book breadth |
| `/psalms` | Individual Psalm citation rankings |
| `/volumes` | Cross-volume comparison table |

> The web app reads from `web/src/data/*.json`, which are regenerated by `python data_processer.py`. Commit the updated JSON files after each pipeline run to update the deployed site.

## Data schema

**`bible_references` SQLite table**

| Column | Type | Description |
|--------|------|-------------|
| `volume` | TEXT | `volume_1` through `volume_9` |
| `author_id` | TEXT | e.g. `origen`, `tertullian` |
| `work_id` | TEXT | e.g. `against_heresies` |
| `book` | TEXT | OSIS book code (e.g. `Matt`, `Ps`) |
| `chapter_start` | TEXT | Starting chapter number |
| `verse_start` | TEXT | Starting verse number |
| `quote_confidence` | TEXT | `exact_citation` or `probable_allusion` |
| `testament_group` | TEXT | `new_testament`, `old_testament_or_other`, `deuterocanonical` |
| `osis_ref` | TEXT | Full OSIS reference string |
| `passage` | TEXT | Human-readable citation label |

## Module overview

| Module | Role |
|--------|------|
| `anf_pipeline/parsing.py` | ThML extraction, OSIS parsing, deduplication |
| `anf_pipeline/models.py` | `Reference` and `ParseReport` dataclasses |
| `anf_pipeline/constants.py` | Book sets, canonical order, display names, author metadata |
| `anf_pipeline/aggregation.py` | CSV writers |
| `anf_pipeline/web_export.py` | JSON export for the Next.js frontend |
| `anf_pipeline/storage.py` | SQLite rebuild and ad hoc SQL |
| `anf_pipeline/query.py` | In-memory reference filtering |
| `anf_pipeline/reporting.py` | Markdown report generation |
| `mcp_server/server.py` | MCP server with 8 tools |
